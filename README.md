# PapiLio Unofficial Archive

PapiLioの非公式ファンアーカイブ。外部ライブラリ・有料サービス・外部フォントは使いません。Node.js 20以上のみ必要です。

## ローカルプレビュー

```sh
cd /workspace/papilio-archive
npm start
```

同じマシンのブラウザで `http://127.0.0.1:3000` を開いてください。クラウドの画面にポート転送機能がある場合はポート3000に接続してください（この環境での転送URLは未確認）。ローカルPCではリポジトリを取得し、同じコマンドを実行できます。

iPhoneから同じWi-Fi内の開発PCを確認する場合は `HOST=0.0.0.0 npm start` とし、PCのLAN IPのポート3000を開いてください。信頼できるネットワーク内でのみ使用してください。Codexのポート転送に対応するため、既定では `0.0.0.0:3000` で待ち受けます。ローカルPC内だけに制限する場合は `HOST=127.0.0.1 npm start` を使ってください。公開・デプロイ処理はありません。

## ページと情報管理

HOME / PROFILE / HISTORY / LIVE / MEDIA はハッシュURLで切り替わります。ライブ詳細は `#/live/公演ID` です。`data.js` の `lives` に公演を追加すると一覧と詳細が生成されます。各公演の `setlist`、`posts`、`videos` を編集して管理します。ブラウザ上の編集や保存機能はありません。

`data.js` のメンバー、年表、SNSリンクも編集できます。公演の登録形式は同ファイルのコメントを参照してください。`status` は `past` または `upcoming`。公演日順に掲載したい場合は配列の順序を調整してください。原則として確認済みの情報と出典URLを登録し、未確認の項目は空にしてください。空のセットリスト・SNS・動画は未確認として表示されます。2025年12月は記録対象期間であり、結成日の主張ではありません。

公演情報・曲名・公式SNS URLは提供されていないため未登録です。名前と担当は制作依頼に基づき、紹介文はサイト用コピーです。画像はコードで描いた抽象表現で、アーティスト写真は使っていません。

## 検証

```sh
npm test
```

HTTP配信・非公開ファイルの拒否・全ページ描画・公演詳細・未確認表示を検証します。iPhone実機での表示確認は別途必要です。

## Codexでのプレビュー

`npm run dev` を起動し、Codexのウェブプレビューでポート3000を選択してください。iPhoneではCodexが提供するプレビューURLを開きます。iPhone自身の `localhost` や `0.0.0.0` はこのクラウド環境を指しません。プレビューURLの発行・転送はCodex側の機能が必要です。環境の再起動後は開発サーバーも再起動してください。
